# Identidade começa.ai

Tokens visuais extraídos do CSS do site oficial, para que as três escolas e os
e-mails falem a mesma língua.

| Token | Valor | Uso |
|---|---|---|
| `marca` | `#1F1BE4` | azul principal |
| `marcaFunda` | `#14119C` | estado ativo |
| `ponto` | `#3B37E9` | padrão de pontos |
| `destaque` | `#FAE047` | amarelo de ênfase |
| `papel` | `#F2F2F2` | fundo |
| `tinta` | `#000000` | texto |

Tipografia: **Host Grotesk** no texto, **JetBrains Mono** nos rótulos.

Exporta ainda `LOGO()` — a marca oficial em SVG, do `favicon.svg` do site — e
`PONTOS()`, o padrão de fundo.
